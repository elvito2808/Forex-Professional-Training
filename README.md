## وضعیت یادگیرنده
بدون تجربه بازار؛ کارشناسی ارشد؛ ریاضیات خوب؛ انگلیسی متوسط؛ Python مقدماتی؛ بریتانیا؛ Windows؛ ۴۰ ساعت در هفته. مسیر شغلی هنوز انتخاب نشده است.

## اصل حاکم
یادگیری و صلاحیت حرفه‌ای از عملکرد معاملاتی جدا ارزیابی می‌شوند. تکمیل زمان یا مطالعه، جایگزین اثبات مهارت نیست. هیچ وعده سود یا درآمد وجود ندارد.
